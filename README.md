# Inkwell – Notebooks & Stationery (E-commerce Frontend)

A beginner-friendly, multi-page e-commerce website built with **HTML5 and CSS only** (no JavaScript, no frameworks).

## Pages
| File | Purpose |
|---|---|
| `index.html` | Home page with hero and featured products |
| `products.html` | Product listing (8 items) |
| `product.html` | Product details with options and quantity |
| `cart.html` | Cart table and order summary |
| `checkout.html` | Delivery address and payment method form |
| `thankyou.html` | Order confirmation |
| `login.html` | Login and register forms |
| `contact.html` | About text and contact form |

## Features
- Responsive layout (CSS Grid, Flexbox and media queries)
- Shared `style.css` with CSS variables for easy re-theming
- Semantic HTML5 and built-in form validation
- SVG product images in `images/`

## Run locally
Download or clone the repo and open `index.html` in a browser.
